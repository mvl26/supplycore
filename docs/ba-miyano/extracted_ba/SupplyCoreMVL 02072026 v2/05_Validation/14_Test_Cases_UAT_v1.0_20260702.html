4. Checklist nghiệm thu

  • 100% UC có ≥1 TC luồng chính + 1 TC ngoại lệ.
  • Kiểm thử cô lập Portal PASS (không rò rỉ chéo).
  • Sổ kho/sổ cái khớp chứng từ; audit trail đầy đủ.
  • Hiệu năng đạt ngưỡng NFR.
