1. Tổng quan API

Hệ thống cung cấp 46 endpoint theo chuẩn Frappe (/api/method/...), nhóm theo 12 phân hệ. Nhóm Portal (M12) tách riêng và áp cô lập dữ liệu.

2. Xác thực

Nội bộ: session hoặc API Key/Secret trong header Authorization: token key:secret. Portal: đăng nhập tài khoản khách, session gắn role SC Customer Portal, mọi truy vấn tự lọc theo khách (permission query). Mọi request nội bộ bị chặn với role Portal (403).
