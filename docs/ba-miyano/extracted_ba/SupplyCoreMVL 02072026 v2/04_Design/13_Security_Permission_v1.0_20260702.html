3. Chính sách bảo mật

  • Xác thực session + API Key/Secret (nội bộ); tài khoản khách cho Portal.
  • Mật khẩu băm bcrypt; kênh HTTPS/TLS 1.2+.
  • Audit trail mọi submit/cancel; không xóa cứng chứng từ đã ghi sổ.
  • Tuân thủ NĐ 13/2023/NĐ-CP; khóa tài khoản nghi vấn khi điều tra.

4. Audit & Cô lập Portal

Permission query gắn portal_user ↔ SC Customer: mọi truy vấn HĐ khung/đơn/lịch sử tự lọc theo khách đăng nhập. Kiểm thử an ninh cô lập là hạng mục UAT bắt buộc (TC-40..43). Mọi hành động ghi get_audit_trail.
