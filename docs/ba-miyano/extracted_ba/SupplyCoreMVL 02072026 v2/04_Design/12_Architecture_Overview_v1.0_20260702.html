1. Tổng quan kiến trúc

Monolithic Frappe app supplycore_mvl, kiến trúc lai: bộ DocType SC-* tự quản sổ kho (SC Stock Ledger) & sổ cái (SC GL Entry), song song mở rộng DocType ERPNext. Cấu hình đặt trong patches/install.py. Bổ sung cổng www/portal cho khách hàng.

2. Phân tầng & 12 phân hệ

3. Data Flow (chiều bán)

Portal (khách đặt) → SC Sales Order → duyệt nội bộ → SC Delivery Note (xuất kho, ghi SC Stock Ledger) → nghiệm thu → SC Sales Invoice (ghi SC GL phải thu) → SC Sales Receipt (thu tiền) → cập nhật cột mốc Portal.

5. Technology Stack

Frappe Framework v15, ERPNext v15, Python, MariaDB 10.6, Redis 7, Docker Compose. Xác thực session + API key (không JWT); Portal dùng tài khoản khách + role cô lập.
